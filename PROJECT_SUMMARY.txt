  PROJECT SUMMARY — Digital Garden / Greenhearth

── ชื่อเว็บไซต์ ────────────────────────────────────────────────────────────────

  Digital Garden  (แบรนด์ชื่อ "Greenhearth")

── เว็บนี้คืออะไร ──────────────────────────────────────────────────────────────

  ร้านค้าออนไลน์ธีม "ธรรมชาติและการทำสวน" ที่มีบริการหลัก 2 อย่างควบคู่กัน
  1. ขายสินค้าผ่าน Shop (e-commerce)
  2. ให้เช่าแปลงผัก พร้อมระบบจองออนไลน์ (Veggie Plot Booking)

── เทคโนโลยีที่ใช้ (Tech Stack) ────────────────────────────────────────────────

  Backend
  ├── Python 3.14
  ├── Django 6.0.1          (Web Framework หลัก)
  ├── SQLite                (ฐานข้อมูล — ไฟล์ db.sqlite3)
  └── Django Admin          (หน้าจัดการข้อมูล /admin/)

  Frontend
  ├── HTML5 + Django Template Language (DTL)
  ├── CSS3                  (แยกไฟล์ต่อหน้า + globals.css ร่วมกัน)
  └── Vanilla JavaScript    (ไม่ใช้ Framework เช่น React/Vue)

  Storage
  └── localStorage (Browser)  — เก็บตะกร้าสินค้าฝั่ง Client

  Dependencies (requirements.txt)
  ├── Django==6.0.1
  ├── asgiref==3.11.0
  ├── sqlparse==0.5.5
  └── tzdata==2025.3

── โครงสร้างไฟล์ ────────────────────────────────────────────────────────────────

  myproject/
  ├── manage.py
  ├── myshop/               ← config โปรเจกต์ (settings, urls, wsgi, asgi)
  ├── store/                ← Django App หลัก (models, views, admin)
  ├── templates/            ← HTML templates ทุกหน้า
  └── static/
      ├── css/              ── stylesheet แยกต่อหน้า
      ├── js/               ── script.js (logic ร่วม)
      └── images/           ── รูปภาพสินค้า, ไอคอน, แบนเนอร์

── หน้าเว็บที่มี (URL Routes) ──────────────────────────────────────────────────

  /                     home.html         หน้าแรก
  /shop/                shop.html         รายการสินค้าทั้งหมด
  /product/<id>/        product_detail.html  รายละเอียดสินค้า
  /cart/                cart.html         ตะกร้า + ชำระเงิน
  /veggie-plots/        Veggie_Plots.html รายการแปลงผักให้เช่า
  /plot-detail/         plot_detail.html  รายละเอียดแปลง + จองแปลง
  /about/               about.html        เรื่องราวของทีม
  /contact/             contact.html      ช่องทางติดต่อ
  /admin/               Django Admin      จัดการข้อมูล backend
  /process-booking/     (POST only)       รับฟอร์มจองแปลงผัก → booking_success.html

── ฟีเจอร์ฝั่ง Shop ─────────────────────────────────────────────────────────────

  • แสดงสินค้า 42 รายการ แบ่ง 4 หมวด:
    - อุปกรณ์ทำสวน (tools)      9 รายการ
    - เมล็ดพันธุ์ (seeds)       12 รายการ
    - ผลิตภัณฑ์ธรรมชาติ (natural) 13 รายการ (น้ำมันหอม, ดอกไม้แห้ง)
    - อโรม่า (aroma)             6 รายการ (เครื่องพ่นไอน้ำ)

  • กรองสินค้าตามหมวดหมู่ (Sidebar filter)
  • เรียงสินค้าตามราคา (Sort: Low→High / High→Low)
  • Quick View Modal — ดูรายละเอียดและเลือกจำนวนก่อน Add to Cart
  • ปุ่ม Add to Cart พร้อม Animation รูปบินเข้าตะกร้า
  • Cart Badge แสดงจำนวนสินค้าในตะกร้าบน Navbar
  • หน้า Product Detail — รูปใหญ่, Tab รายละเอียด/รีวิว, สินค้าแนะนำ slider

── ฟีเจอร์ฝั่ง Cart / Checkout ─────────────────────────────────────────────────

  • ตะกร้าสินค้าเก็บใน localStorage (ไม่ต้องล็อกอิน)
  • เพิ่ม/ลดจำนวนสินค้าในตะกร้า (real-time, ไม่ reload หน้า)
  • ลบสินค้าออกจากตะกร้า
  • คำนวณยอดรวม + ค่าจัดส่ง + ส่วนลดอัตโนมัติ
  • โค้ดส่วนลด (Mockup: GREEN2026 ลด $10)
  • ที่อยู่จัดส่ง: เลือก/เพิ่ม/ลบ ที่อยู่ใน Popup Modal
  • คำนวณวันที่คาดว่าจะได้รับสินค้า (วันปัจจุบัน + 3 วัน)
  • ฟอร์มขอใบกำกับภาษี (Toggle แสดง/ซ่อน)
  • เลือกวิธีชำระเงิน: QR PromptPay / บัตรเครดิต / COD
  • หมายเหตุถึงผู้ขาย

── ฟีเจอร์ฝั่ง Veggie Plot Booking ────────────────────────────────────────────

  • แสดง 6 แปลงผักพร้อมสถานะ (ว่าง/ไม่ว่าง)
  • แต่ละแปลงมีข้อมูล: ขนาด, ประเภทแสง, ราคา/เดือน
  • หน้า Plot Detail:
    - สลับรูปภาพหลัก/ภาพย่อ (Gallery swap)
    - เลือกพืชที่ต้องการปลูก (12 ชนิด) พร้อม Popup แสดงทั้งหมด
    - ปฏิทินเลือกวันเริ่มปลูก (จองล่วงหน้าไม่เกิน 60 วัน)
    - คำนวณวันเก็บเกี่ยวและราคา (฿/วัน × จำนวนวันที่โต)
    - ปุ่ม "Book Plot" ส่ง Form → Django Backend → หน้ายืนยัน

  พืชที่รองรับ (Backend คำนวณได้):
    มะเขือเทศ(75วัน), แครอท(75), ผักกาดหอม(37), พริกหวาน(75),
    แตงกวา(52), ข้าวโพด(75), ทานตะวัน(75), มันฝรั่ง(105),
    โหระพาไทย(24), สตรอว์เบอร์รี(105), บลูเบอร์รี่(912), ราสป์เบอร์รี่(547)

── ฟีเจอร์ UI ร่วมกัน (ทุกหน้า) ──────────────────────────────────────────────

  • Navbar: Logo + เมนู 5 รายการ + Cart Badge + Profile Dropdown
  • Profile Dropdown: เมนู "การซื้อของฉัน" / "ออกจากระบบ"
  • Chat Popup (Live Chat Mockup): เปิด/ปิดได้, พิมพ์ข้อความส่งได้
  • Footer: ลิงก์ Explore/Support + Newsletter input
  • ทุกหน้า responsive (mobile-friendly)
